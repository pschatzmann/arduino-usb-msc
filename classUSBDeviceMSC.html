Detailed Description

Exports a block driver to the USB host (PC) as a USB drive.

The driver can be any class with the FatFs style block interface (disk_initialize(), disk_status(), disk_read(), disk_write(), disk_ioctl()): every fatfs::IO of TinyFATFS and every tinyext4::IO of TinyEXT4, or your own class. Only 512-byte sectors are supported.

#include "USBDeviceMSC.h"
#include "fatfs.h"
fatfs::RamIO ram(256); // 128 KB, formatted by SDClass::begin()
USBDeviceMSC msc;
void setup() { msc.begin(ram); }

Registers the MSC interface and exports io (which must outlive the export). Must be called before the USB stack starts: on boards where the core starts USB itself (RP2040, SAMD, nRF52) call it first thing in setup(), before Serial.begin(); on ESP32-S2/S3 it calls USB.begin() for you unless startUsb is false (set it false if you add other USB classes and call USB.begin() yourself).
