◆ begin()

bool USBDeviceMSC::begin ( USBMscBlockDevice &  dev,
bool  startUsb = true 
)

Registers the MSC interface and exports dev. Must be called before the USB stack starts: on boards where the core starts USB itself (RP2040, SAMD, nRF52) call it first thing in setup(), before Serial.begin(); on ESP32-S2/S3 it calls USB.begin() for you unless startUsb is false (set it false if you add other USB classes and call USB.begin() yourself).
