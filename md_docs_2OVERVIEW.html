Host mode – the board reads a USB stick Device mode – the board is a USB stick

Examples USBHostMSC_* USBDeviceMSC_*

Host and device mode use the USB controller in opposite roles, so one controller cannot do both at once. On RP2040 you pick one with the USB Stack menu; both together need two controllers (e.g. a MAX3421E host chip next to the native device port). See BOARDS.md.
