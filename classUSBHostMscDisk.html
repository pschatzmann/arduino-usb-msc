Detailed Description

One USB mass storage device (LUN) as a device of 512-byte sectors: the common part of the filesystem drivers USBHostMscFatIO (TinyFATFS) and USBHostMscExt4IO (TinyEXT4).

It is bound to a device by init() (the filesystem calls it when it mounts). Once that device is unplugged, ready() is false and every transfer fails until init() binds again – even if another drive shows up at the same USB address in the meantime. So a filesystem never writes what it cached from one drive onto another one.

With dev_addr == kAnyDevice, init() binds to the first mounted mass storage device: convenient with a single drive. Use explicit addresses (from USBHostMSC::onMount()) when several drives are attached via a hub.
