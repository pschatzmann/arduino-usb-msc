Detailed Description

Adapter that turns a connected TinyNBD client into a USBMscBlockDevice, so a remote NBD export can be.

  • mounted with USBMscFatFS / USBMscExt4FS / USBMscAutoFS (begin(dev)), or
  • exported to a PC as a USB drive with USBDeviceMSC::begin(dev).

Needs the TinyNBD library (https://github.com/pschatzmann/arduino-nbd). It is header-only and not included by any other header of this library, so TinyNBD is only required in sketches that include this file.
