usb-msc

[](LICENSE)

USB Mass Storage for Arduino – the "USB stick" protocol, in both directions:

  • USB host: your board is the computer. Plug a USB flash drive into the board and read/write its files (FAT, exFAT, ext2/3/4), no SD card slot needed.
  • USB device: your board is the USB stick. Plug it into a PC and it shows up as a drive, backed by RAM, an SD card or any storage you provide.

A board's USB port does one role at a time; pick it in the board's USB menu.

This library does the USB part only. The filesystems are TinyFATFS (FAT12/16/32, exFAT) and TinyEXT4 (ext2/3/4), used with their own API. Both directions meet at their block driver interface:

  • Host: USBHostMscFatIO / USBHostMscExt4IO are block drivers for a plugged-in USB drive, like the SD card drivers of those libraries.
  • Device: USBDeviceMSC exports any block driver of those libraries (RAM disk, SD card, NBD export, ...) or your own to the PC.
#include "USBHostMSC.h"
#include "USBHostMscFatIO.h"
USBHostMSC msc;
USBHostMscFatIO usbIO(msc); // the plugged-in drive
fatfs::SDClass usbFat; // TinyFATFS
void onMount(uint8_t) {
if (usbFat.begin(usbIO)) {
fatfs::File f = usbFat.open("/hello.txt");
while (f.available()) Serial.write(f.read());
}
}
void onUnmount(uint8_t) { usbFat.end(); }
void setup() {
msc.onMount(onMount);
msc.onUnmount(onUnmount);
msc.begin();
}
void loop() { msc.task(); }
