◆ aliveToken()

std::shared_ptr< bool > usbmscfs::Backend::aliveToken ( ) const
inline

Shared liveness flag: true while this Backend exists. Adapters that keep a Backend& beyond the Backend's lifetime (open files, fs::FS impls) hold a copy and check it before every use, since a USB drive can be unplugged – destroying the Backend – while the sketch still holds File objects.

◆ detachAll()

void usbmscfs::Backend::detachAll ( )
inlineprotected

Closes every still-open file (while the derived class's filesystem state is still valid) and marks this Backend dead. Derived destructors must call this FIRST, before tearing down their state; it is idempotent.
