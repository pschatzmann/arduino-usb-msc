Detailed Description

FAT12/16/32/exFAT filesystem backend built on TinyFATFS.

Kept as an opaque pimpl so that <fatfs.h> (a header-only library) is only ever #include'd from USBMscFatBackend.cpp – including it from more than one translation unit would cause duplicate-symbol link errors.
