Detailed Description

Blocking wrapper around TinyUSB's USB Host Mass Storage (tuh_msc_*) class driver. One instance manages the single on-board host controller; multiple mass storage devices (e.g. behind a hub) are addressed by their TinyUSB device address.

◆ task()

void USBHostMSC::task ( )

Pump the TinyUSB host stack. Call as often as possible from loop(). On ESP32 the stack runs on its own task; task() then delivers pending mount/unmount events – filesystem mounting and your onMount() / onUnmount() callbacks run from here, in loop() context.
