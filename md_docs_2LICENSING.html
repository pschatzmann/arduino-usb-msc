Licensing and dependencies

usb-msc's own code (USBHostMSC, USBDeviceMSC, USBMscRamDisk, USBMscPartition, the filesystem backend abstraction, the STM32 port) is MIT.

Filesystem support comes from two header-only libraries, installed as normal Library Manager dependencies (depends= in library.properties):

  • TinyFATFS (FAT12/16/32, exFAT) – MIT wrapper around ChaN's FatFs, which has its own permissive BSD-1-Clause-style license: source redistribution must keep the copyright notice, binary-only redistribution (compiled firmware) needs no attribution.
  • TinyEXT4 (ext2/3/4) – MIT.

Only the classes your sketch references are linked into the firmware. Nothing in the dependency chain is copyleft.

Device mode builds on the USB device MSC class of the platform (the arduino-esp32 core's USBMSC, or Adafruit_USBD_MSC from the Adafruit TinyUSB Library, MIT). USBMscSdCard additionally needs the SdFat library (MIT), only when your sketch includes USBMscSdCard.h.
