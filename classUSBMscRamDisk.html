Detailed Description

Simple RAM disk. Pass your own buffer (size = blocks * 512) or let it malloc one. The content is lost on reset; it is not formatted – format() writes a minimal FAT12/16 filesystem so that hosts accept it (requires at least ~64 blocks, i.e. 32 KB).

Adds a file to the root directory of the volume written by format(). name is 8.3 ("HELLO.TXT", upper case). Files are stored contiguously, so call it right after format() and before the PC gets the drive. Returns false if the name is invalid or the volume/root is full.
