1/*
2 * usb-msc -- USB *device* mode Mass Storage
3 *
4 * The counterpart of USBHostMSC: instead of reading a USB stick, the board
5 * *is* one. A PC that is plugged into the board's USB port sees a drive
6 * whose blocks are served by any USBMscBlockDevice (RAM disk, SD card,
7 * SPI flash, ... or your own subclass).
8 *
9 * Built on the device-mode MSC class that is already part of the platform:
10 * - ESP32-S2/S3 (arduino-esp32 core): the core's USBMSC. Select
11 * Tools > USB Mode > "USB-OTG (TinyUSB)".
12 * - everything else (RP2040, SAMD, nRF52, STM32, ...): Adafruit_USBD_MSC
13 * from the "Adafruit TinyUSB Library". On RP2040 select
14 * Tools > USB Stack > "Adafruit TinyUSB" (the *device* stack, not
15 * "...Host (native)").
16 *
17 * Device and host mode need separate USB controllers; this class and
18 * USBHostMSC can only run at the same time on boards that have two
19 * (e.g. RP2040 with PIO-USB for the host side, or a MAX3421E host chip).
20 *
21 * Only one USBDeviceMSC instance (a single LUN) is supported.
22 *
23 * Do not let the MCU modify a filesystem on the exported medium while the
24 * PC has it mounted -- the PC caches aggressively and both sides would
25 * corrupt each other. Use USBDeviceMSC::mediaPresent(false) to "eject"
26 * while the MCU accesses the data, then mediaPresent(true) again.
27 */
