Detailed Description

template<typename FSType, uint8_t MaxDevices>
class USBMscFSPool< FSType, MaxDevices >

Mounts up to MaxDevices FSType filesystems simultaneously, one per USB Mass Storage device address – e.g. several flash drives behind a hub. Works on ESP32, RP2040 and STM32.

FSType is any class with the same shape as USBMscFatFS/USBMscExt4FS/ USBMscExt4FSReadOnly/USBMscAutoFS: bool begin(USBHostMSC&, uint8_t), void end(uint8_t), bool mounted(), and a fs() accessor. fs()'s return type isn't hardcoded here – it's deduced from whatever FSType's own fs() returns, which is fs::FS& on ESP32/RP2040 but a self-reference (e.g. USBMscFatFS&) on STM32 (see USBMscFatFS.h/USBMscExt4FSBase.h). That's what lets this same template work unchanged on all three platforms, unlike USBMscAutoFS (not yet ported to STM32 – see the wiki page STM32 – because that class needs USBMscFatFS::fs() and USBMscExt4FSBase::fs() to return the same type so it can pick between them at runtime; USBMscFSPool never mixes two different FSTypes in one instance, so it never faces that problem).

USBMscFSPool<USBMscFatFS, 4> pool; // up to 4 FAT drives at once
USBHostMSC msc(&pool);
void onMount(uint8_t dev_addr) {
if (pool.mounted(dev_addr)) {
File f = pool.fs(dev_addr).open("/hello.txt", "r"); // USBMscFile on STM32
...
}
}

Storage for all MaxDevices FSType instances is a fixed-size member array – no heap allocation, but every slot's RAM/flash cost (FatFs buffers, TinyEXT4 caches, ...) is paid MaxDevices times over, whether or not that many devices are ever actually plugged in. Size MaxDevices to how many devices you actually expect (a typical hub has 4 ports), not to CFG_TUH_DEVICE_MAX (and, if FSType is USBMscFatFS, not beyond TinyFATFS's own FF_VOLUMES=4 – see that library's src/ff/ffconf.h).

The filesystem mounted for dev_addr. PRECONDITION: mounted(dev_addr) is true – there is no "null reference", so calling this for an unmounted device is undefined behaviour. Use get() for a checked lookup. Return type is deduced from FSType::fs() – see the class comment. decltype(auto), not auto: plain auto would strip the reference and return a (sliced, for polymorphic FSTypes) copy instead.
