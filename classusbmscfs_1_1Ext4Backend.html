Detailed Description

ext2/ext3/ext4 filesystem backend built on TinyEXT4 (MIT), a header-only ext implementation without journaling.

Kept as an opaque pimpl so that TinyEXT4's headers are only ever #include'd from USBMscExt4Backend.cpp.

ext4 (extents + filetype) mounts read/write unless the caller asked for read-only; ext2/ext3, filesystems with a pending journal recovery, and filesystems using features TinyEXT4 can't write are mounted read-only (see isReadOnly()).
